# Example Programs

1. `logic_flags.asm`: Exercises `AND/OR/XOR/SHL/SHR/CMP` and arithmetic flags.
2. `counter_loop.asm`: Simple countdown loop using `SUB`, `JZ`, and `JMP`.

Assemble and run a program:

```powershell
.\scripts\run-asm.ps1 -Source programs\logic_flags.asm
```

```bash
bash scripts/run-asm.sh --source programs/logic_flags.asm --no-waves
```
